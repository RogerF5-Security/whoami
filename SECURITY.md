# Política de seguridad

Para comunicar una posible vulnerabilidad del portafolio, utiliza **Security → Report a vulnerability**:

https://github.com/RogerF5-Security/whoami/security/advisories/new

Incluye la URL o componente afectado, la revisión, los pasos de reproducción y el impacto. No adjuntes credenciales ni documentos internos de empresas o clientes.

Este repositorio contiene el portafolio público. Las incidencias de otras herramientas deben comunicarse en sus respectivos repositorios. Los enlaces rotos y las correcciones de presentación pueden abrirse como issues públicos.

La rama principal representa la versión mantenida del sitio.
